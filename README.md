
# Retail Banking Transaction Analysis | Power BI

## Project Overview
An interactive Power BI project analyzing retail banking customers, accounts, transactions, loans, and card usage through KPI dashboards and business insights.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Modeling
- MySQL

## Dashboard: Customer Profile & Segmentation
The dashboard analyzes customer demographics, customer segments, credit score bands, KYC status, age groups, state-wise distribution, and average customer tenure.

### Key Performance Indicators (KPIs)
- **Total Customers:** 500
- **Active Customer Rate:** 75%
- **Average Annual Income:** 152K
- **Average Credit Score:** 683

## Project Objectives
- Analyze customer profiles and segments.
- Understand account usage and branch activity.
- Identify transaction patterns and trends.
- Evaluate loan performance and repayment behavior.
- Analyze card usage and product engagement.
- Develop an executive summary with key business insights.

## Business Value
This project aims to help stakeholders understand customer behavior, monitor banking activities, evaluate product engagement, and support data-driven decision-making.

## Project Files
- `Retail_Banking_Analysis_PBI.pbix` — Power BI report
- `README.md` — Project documentation
- `Screenshots/` — Dashboard screenshots

## How to Use
1. Download or clone this repository.
2. Open the `.pbix` file using Microsoft Power BI Desktop.
3. Explore the available dashboards and visualizations.
4. Configure data source paths if refreshing the report is required.
